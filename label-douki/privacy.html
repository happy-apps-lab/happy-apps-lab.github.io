ラベル同期連絡帳 for Google Contacts（以下「このアプリ」）

このアプリが使う情報

このアプリは、利用者がGoogleアカウントでログインしたときに、Googleの連絡先（名前、ふりがな、電話番号、メールアドレス、会社、住所、誕生日、ウェブサイト、メモ、ラベル）を読み書きします。

Googleに求める権限は、連絡先の読み書き（https://www.googleapis.com/auth/contacts）だけです。メール、カレンダー、写真など、ほかの情報には触れません。

情報の使い方

  • 連絡先は、アプリの画面に表示するため、利用者が追加・変更・削除した内容をGoogleに保存するためにだけ使います。
  • 連絡先は、このiPhoneとGoogleの間だけでやりとりします。開発者のサーバーはありません。開発者が連絡先を見ることはできません。
  • 連絡先を、広告、分析、第三者への提供、販売に使うことはありません。

iPhoneの中に保存するもの

  • Googleへのログインの通行証（トークン）：iPhoneのキーチェーンに、この端末だけで使える形で保存します。
  • 連絡先の写し：すぐに開けるように、アプリの中に保存します（端末の暗号化で保護し、iCloudなどのバックアップには入れません）。
  • ラベルの並び順や、表示の設定。

ログアウトと削除

  • 「ログアウト（連絡先は残す）」：通行証を消し、Googleでもこのアプリの許可を取り消します。連絡先の写しは、iPhoneの中に残ります。
  • 「ログアウトして、このiPhoneから消す」：通行証と、連絡先の写し、ラベルの並び順を、iPhoneから消します。
  • アプリを削除すると、アプリの中のデータは消えます。Googleの「アカウント → セキュリティ → サードパーティ製のアプリとサービス」からも、いつでも許可を取り消せます。
  • Googleの連絡先そのものは、Googleに残ります。

広告（無料版のみ）

無料版では、画面の下に、このアプリの有料版のご案内（自社の広告）を表示します。ほかの会社の広告は表示しません。

広告のために情報を集めたり、外部に送ったりすることはありません。広告の会社の仕組み（SDK）も、このアプリには入っていません。

有料版にすると、このご案内は表示されません。

購入

有料版の購入は、AppleのApp Storeで行われます。カードなどの支払いの情報を、このアプリや開発者が受け取ることはありません。

Google API サービスのユーザーデータに関するポリシー

このアプリによる、Google APIから受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に従います。

Privacy Policy (English)

Label Sync Contacts for Google Contacts (ラベル同期連絡帳, "the App") — iOS app by Happy Apps Lab

1. Google user data the App accesses

When the user signs in with Google, the App requests only one scope: https://www.googleapis.com/auth/contacts (People API). With it, the App reads and writes the user's own Google Contacts: names, phonetic names, phone numbers, email addresses, company, addresses, birthday, websites, notes, and contact groups (labels). The App does not access Gmail, Calendar, Drive, Photos or any other Google data. The App does not create aggregated or anonymized data from Google user data.

2. How the App uses Google user data

Google user data is used only to provide the App's user-facing features: showing the user's contacts and labels, calling / messaging a contact, and saving the contacts and labels the user adds, edits or deletes back to the user's Google Contacts. All changes are made only when the user takes an action in the App.

3. Sharing and transfer

Google user data is exchanged only between the user's iPhone and Google's People API. The developer has no server and cannot see the user's contacts. Google user data is not shared with, transferred to or sold to any third party (including advertisers, data brokers, analytics providers or AI/ML services), and is not used for advertising, profiling, credit or lending decisions, or to train AI/ML models. The free version shows only an in-app banner for the App's own paid upgrade. The App contains no third-party advertising or analytics SDK, and no data is collected for advertising.

4. Data protection

All communication with Google uses HTTPS. The OAuth refresh token is stored in the iOS Keychain (this-device-only, accessible only when the device is unlocked); the access token is kept only in memory. A local copy of the contacts is stored inside the App's sandbox with iOS Data Protection (complete file protection) and is excluded from iCloud / device backups.

5. Data retention and deletion

The local copy is kept only on the user's device so contacts can be shown quickly and offline. "Log out (keep contacts)" deletes the token and revokes the App's Google access; "Log out and delete from this iPhone" also deletes the local copy and settings. Deleting the App removes all of its data from the device. Users can also revoke access at any time from their Google Account (Security → Third-party apps & services). The user's contacts themselves stay in their Google account and are never stored by the developer.

6. Limited Use

The App's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
